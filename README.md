# To-Do List Angular

## Description

Cette application est une To-Do List développée avec Angular et TypeScript dans le cadre d'un projet d'apprentissage.

Elle permet de :

- Ajouter une tâche
- Modifier une tâche
- Supprimer une tâche
- Marquer une tâche comme terminée
- Afficher le nombre total de tâches
- Afficher le nombre de tâches terminées

L'objectif de ce projet est de mettre en pratique les notions de HTML, CSS, JavaScript, TypeScript et Angular, notamment les composants, les services, le data binding et les événements.

---

## Technologies utilisées

- Angular
- TypeScript
- HTML
- CSS

---

## Installation

Installer les dépendances :

```bash
npm install
```

---

## Lancer l'application

Démarrer le serveur de développement :

```bash
ng serve
```

Puis ouvrir le navigateur à l'adresse :

```text
http://localhost:4200
```
